การ์ดในแชต LINE ของ June (Flex message)

บอตตอบลูกค้าเองด้วยการ์ดแบบนี้ ข้อมูลดึงจากหลังร้าน (เมนูขนม, ข้อมูลร้าน, โปรโมชั่น) แก้ที่เดียว เว็บกับ LINE เปลี่ยนตาม · ตัวหนังสือในการ์ดเป็นฟอนต์ของมือถือ เพราะการ์ด LINE ใส่ฟอนต์เองไม่ได้ · ร้านยังแชตตอบเองได้เหมือนเดิม

  • ข้อความตอนเพิ่มเพื่อนเป็นการตอบกลับ ไม่กินโควตาข้อความ

ดูที่ร้าน
  • วันก่อนรับ ส่ง "พรุ่งนี้มารับขนมนะคะ" ได้ด้วย (แบบ tiewy เตือนก่อนนัด)
  • QR พร้อมเพย์ในการ์ด: ยังไม่ใส่ เพราะตกลงไว้ว่าเว็บไม่รับเงินเอง ถ้าจะใส่ต้องคุยกันก่อน

ร้านต้องทำอะไร (ครั้งเดียว)

  • LINE OA Manager → ตั้งค่า → Messaging API → เปิดใช้ แล้วส่ง channel secret กับ access token ให้ผม (ใส่ใน secret ของ Fly ไม่พิมพ์ในแชต)
  • ตั้งโหมดตอบกลับเป็น "แชต + Webhook" ร้านยังตอบเองได้ · ปิดข้อความทักทายเดิม (การ์ดต้อนรับมาแทน)

บอตตอบคำไหน

  • เมนู / ราคา / มีอะไรบ้าง → การ์ดเมนู · โปร / ลด / โปรโมชั่น → การ์ดโปร · อยู่ไหน / ที่ร้าน / เปิดกี่โมง → การ์ดที่ร้าน
  • ข้อความอื่นทั้งหมด บอตเงียบ ร้านตอบเองตามปกติ
